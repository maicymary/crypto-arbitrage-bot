# AI-Powered Crypto Arbitrage Bot

This project is a Python-based automated trading bot that identifies arbitrage opportunities between Binance and MEXC exchanges.

## Features
- Real-time price monitoring
- Automated buy/sell execution
- Telegram notifications
- Error handling

## Tech Stack
- Python
- CCXT
- Requests
- Binance API
- MEXC API
- Telegram Bot API
